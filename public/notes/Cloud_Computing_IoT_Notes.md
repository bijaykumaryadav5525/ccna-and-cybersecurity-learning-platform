# Cloud Computing and IoT

The original presentation is kept outside the lightweight GitHub source package. Use the application quizzes and Q&A sections for the included study material.

## Study outline

- Cloud service models: IaaS, PaaS, and SaaS
- Deployment models: public, private, hybrid, and community cloud
- Virtualization, containers, serverless computing, and edge computing
- Cloud security, identity, availability, backup, RTO, and RPO
- Internet of Things architecture, devices, protocols, and security risks
- Monitoring, scalability, load balancing, and disaster recovery
